## Project Description

This repository contains an AI Impact Assessment for TalentScreen AI, a fictional high-risk hiring system that scores and filters job applications. The assessment examines risks to applicants, including discriminatory screening, unclear rejection decisions, and erroneous rejections at scale, and proposes controls to reduce those risks.

## Frameworks Applied

- **NIST AI Risk Management Framework (AI RMF)**
  - **Map** — Describe the hiring context, identify affected stakeholders, and document potential benefits and harms.
  - **Measure** — Assess each risk by likelihood and severity, then prioritize it using the resulting score.
  - **Manage** — Propose mitigation controls, escalation procedures, and ongoing monitoring.
- **EU AI Act** — The assessment classifies TalentScreen AI as high-risk under **Annex III, point 4(a)**, which covers AI used to analyze and filter job applications or evaluate candidates.
